# car-maintenance-guide

자동차 정비 정보를 **차량 식별 → 정비 주제** 순으로 쉽게 찾는 소비자용 공개 저장소입니다.

## 탐색 구조
국산차/수입차 → 제조사 → 차종 → 세대/플랫폼 → 연식 → 엔진/연료(확장 예정)

첫 화면 검색창에서는 다음처럼 바로 찾을 수 있도록 설계합니다.

- 2007 쏘나타 NF
- 2010 그랜저 TG
- 2011 벤츠 E200 CGI
- BMW F10 엔진오일

## 공개 원칙
- 공개 데이터에는 원본 URL, 수집 endpoint, collector, parser, 내부 source id를 넣지 않습니다.
- 필요한 공식 원본 연결은 향후 opaque public ref + 서버측 resolver 방식으로 제공합니다.
- 위험도가 높은 정비는 세부 DIY 절차 대신 전문 정비 권장과 점검 정보 중심으로 제공합니다.
- 차량/연식/엔진이 확인되지 않은 수치는 확정값으로 표시하지 않습니다.
